## Regressions and new findings

- **R1. Option words overflow their boxes (Terminal value, Cost of capital; all widths for Terminal, 1280/1180 for Cost of capital).** "Mature company: risk-free rate plus the mature-r" is cut inside the 2/5-width Method selectbox at 1366 and "…plus the ma" at 1280; "Built from beta and del" (1280) / "Built from beta and" (1180) in the 1/4-width Method box; the metric label "Equity risk premium (from St…" is cut at 1280 and 1180. The full text shows only in the dropdown or on hover. Fix: shorter option words ("Mature company", "Build from beta and debt" → "From beta and debt", "One typed rate") with the long form as the help text, and give the Terminal Method column 3/6 instead of 2/5; metric label "Equity risk premium". `googl-1366-b/tiles/page-05-t00.png`, `mrvl-1280-b/tiles/page-06-t00.png`, `googl-1180-b/tiles/page-06-t00.png`.
- **R2. Risk-free checkbox label ellipsis at 1280/1180** (item 22 above). `mrvl-1280-b/tiles/page-05-t00.png`.
- **R3. "by rule (by rule)" on every Terminal page, both companies (18 hits).** The YAML reasons still contain "(§18.4 rule 5)" after "by rule", and `app_core._RULES` replaces "(§18.4 rule N)" with "(by rule)". Fix: delete the citation from the six YAML reasons (content pass), and make the replacement drop the parenthesis entirely when the sentence already says "by rule". `googl-1366-b/tiles/page-05-t00.png`, `mrvl-1280-b/tiles/page-05-t00.png`.
- **R4. Doubled case name in stop messages** (item 2 above). `probe-b/tiles/terminal-growth-6-t02.png`.
- **R5. "Sources: unknown top-level key (ignored)" in Results Warnings, both companies.** The content pass added a top-level `sources:` block at the end of each `assumptions.yaml` (GOOGL line 443, MRVL line 394); the validator's ignore-warning reaches the owner as a raw line. Fix: accept `sources` in the schema (it is useful) or move it under an existing key, and route validator ignore-warnings to the log rather than the Warnings expander. `googl-1366-b/tiles/page-10-t01.png`.
- **R6. A collapsed table inside a Working note (MRVL Reinvestment, Base case, Sales-to-capital).** The `detail` field holds a whitespace-aligned table ("Year ΔRevenue Capex D&A Acq Formula … FY2023 +1,457 206 305 112 13.6 to ~107 663 to 2.2 …"); markdown collapses the spacing so the columns run together, and it uses the banned "Δ". Fix: render `detail` lines that look like a table as a small `st.table`, or have the content pass write it as a markdown table. `mrvl-1280/tiles/page-07b-expanded-t01.png`, `-t02.png`.
- **R7. File changed on disk while the walk was open is shown as the owner's "Unsaved changes".** During the first 1180 pass the builder saved `assumptions.yaml`; Results then listed "Unsaved changes (26)" with rows such as "Bridge: non-operating asset 1 working notes \| Note 3 footnote 1 reads… \| empty", none of them the owner's, and Save would have been refused only on pressing it. An owner will hit this whenever `draft-valuation` re-runs while the app is open. Fix: compare the file's mtime with the load time on every rerun and show one banner ("The assumptions file changed on disk since you loaded it; use Start over to reload") instead of listing the file's edits as changes. `googl-1180/tiles/page-10-t01.png`, `-t02.png`.
- Cosmetic residues carried from the table: "Year 1" wrap in the Stories mini tables (20); "recorded below… 'used as' column below" in the management note on Reinvestment, Taxes and Results, where no guidance table follows (the note is only right on Revenue growth and Operating margin); Source captions with the raw cache path "cached tools/valuation/data/damodaran/betas.csv" (YAML source strings).

## What works well now (keep)

- Every error state reads as one plain sentence; no `**`, no dotted paths, no decimals-as-rates anywhere on the happy or unhappy path.
- Working-notes fold-outs: the page reads in one pass and the arithmetic is one click away; the history lines with their captions give the yardstick before the cases.
- Start: aligned market inputs with fetched values and dates, one-row-per-factor ranking, the glossary.
- Stories: the two defining paths as five-row tables read instantly side by side at 1280.
- Cost of capital: the shared "How the rate is built" block with the two metrics and the single per-case override row.
- Results: value labels on bars, complete year-by-year and bridge tables, worded Unsaved-changes rows, "What to do now" with disabled Write and captioned Record, Start over behind an expander with confirmation.
- Facts check at half its former height with Show reasons on demand; scroll-to-top on every Next; the "(as loaded …)" reference in the readout.

# Restrained interaction motion — independent audit

**PASS.** Audited 2026-09-10 in Playwright Chromium at 1180 × 820, using isolated EXMP preview `http://127.0.0.1:8516`. No production data or fixture files were written.

## Evidence

- Opened, captured, and visually inspected all 15 pages. No page exceptions, document-level horizontal overflow, text clipping, or layout regression appeared.
- Instrumented the browser's actual `Element.animate` calls: all 14 changes of page in the complete navigation run triggered exactly one entrance animation on `.st-key-page_content`. Clicking the already-selected Overview triggered none. The animation lasts 240 ms, opacity 0.35 → 1 and vertical translation 8 px → 0. The live-value strip is outside its target.
- A numeric edit triggered **zero page entrance animations**. Base first-year revenue growth 20% → 21% recomputed 41.72 → 42.09, with +0.38 since load. Navigation to Review preserved the edit and displayed saved 20.0% versus current 21.0%; report writing remained disabled pending Save.
- Opening a disclosure applied `disclosure-reveal` for 0.16 seconds. Native controls remained clickable.
- Found hover styling overriding the pressed scale. Builder restricted hover styling to `:not(:active)`. Final real pointer-down inspection confirmed `matrix(0.985, 0, 0, 0.985, 0, 0)`.
- With `prefers-reduced-motion: reduce`, the added page entrance triggered **zero calls**, disclosure fade became `none`/`0s`, button transforms became `none`, and CSS transitions became `0s`.
- Save implementation and other financial logic are unchanged by this motion work. The earlier independent Mercury audit covers fixture Save and stale-file guards; this pass rechecked edit/navigation/review integration without repeating file writes.

## Reduced-motion expander correction

Initially, Streamlit's expander independently ran a visible 500 ms Web Animations API height transition in reduced-motion mode. The final reduced-motion CSS overrides its visual height and immediately hides inert content. A bounded final browser check sampled opening and closing at 0, 60, 240, and 540 ms: opening height was immediately 211.75 px at every sample, content displayed and non-inert; closing height was immediately 40 px at every sample, content hidden and inert. The framework finishes its internal open-state change later, but its scheduled animation produces no visual interpolation. The tested page, button, fade, and expander-height motion is fully suppressed under reduced-motion.

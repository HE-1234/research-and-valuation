## Conversion tools

- PDF: `pdftotext -layout` (poppler 24.02.0), form feeds retained so page N of the `.txt` = PDF page N. `pdftotext -bbox` was run on the two earnings decks to check chart pages for value labels (none found on the bar charts); bbox output stayed in `/tmp`. PDFs deleted after conversion.
- HTML (SEC exhibits): python3 + BeautifulSoup 4.13.5 (`html.parser`), script `/tmp/sndk-orch/ir/html2txt.py`: dropped `<script>`, `<style>`, `ix:header` and `display:none` elements; each `<tr>` rendered as one line with " | " between non-empty cells, gluing split "$", "(" and ")%" cells onto the adjacent number; block elements separated by newlines; whitespace (incl. non-breaking spaces) collapsed; consecutive blank lines collapsed. The SGML `<DOCUMENT>` wrapper lines (EX-99.1 / sequence / filename) are kept at the top, matching the format of the pre-existing `press-release.txt`.
- HTML (IR news release): same approach on the page's `<main>` element with navigation lists removed (`/tmp/sndk-orch/ir/nr2txt.py`).
